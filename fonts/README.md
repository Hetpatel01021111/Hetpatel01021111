# Embedded fonts

Instrument Serif (regular and italic), Geist (400 and 600), and Geist Mono (400)
are SIL Open Font License 1.1 fonts from the [Google Fonts source snapshot].
These WOFF subsets contain printable ASCII and the punctuation and arrows used
by the SVG cards. Geist and Geist Mono were instantiated at their listed
weights before subsetting. Each family's copyright and license accompany the
subsets in this directory.

[Google Fonts source snapshot]: https://github.com/google/fonts/tree/06bfe0d62a98375cb09c942fa18e68bd32cff057/ofl
